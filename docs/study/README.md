# Open in Obsidian

1. Clone this repository.
2. In Obsidian, choose **Open folder as vault** and select the repository root or `docs/`.
3. Start at [`00-interview-dashboard.md`](00-interview-dashboard.md).
4. Use Graph view to navigate standard Markdown links, tags, and aliases; no community plugin is required.
5. Follow [`02-seven-day-study-plan.md`](02-seven-day-study-plan.md) for a bounded sequence.
